EquityCurve

Pyth-anchored tokenized-stock launches on Meteora's Dynamic Bonding Curve.
Best Use of Meteora DBC · CWF side-track · $20K USDC · Live on mainnet

The Thesis

Tokenized equities launch at the wrong price and nobody trusts the pool. EquityCurve makes the Dynamic Bonding Curve the launch mechanism for synthetic stocks by pinning the curve's start price to oracle fair value — so the first swap prints the token exactly where Pyth says the asset trades, then climbs to the migration price.

Real DBC Usage (live, not a mock)

Fair-Value Monitor
Reads live DBC virtual pools straight from the dbcij3LWUppWqq96dh6gJWwBifmcGfLSB5D4DuSMaqN program; derives spot via on-chain sqrt price; converts to USD with the on-chain SOL/USD push feed; shows premium/discount vs Pyth + migration progress.
Curve Studio
Enter a ticker → live reference quote → supply/decimal/fee params → generate a full DBC ConfigParameters via buildCurveWithCustomSqrtPrices — start price pinned so the first swap prints the token at Pyth fair value.

How the DBC is original

  • Uses @meteora-ag/dynamic-bonding-curve-sdk against real mainnet pools (ASTROCOW/USDC, scade/SOL) — no testnet, no mock states.
  • Curve config tuned for equity-like assets: oracle-pinned start sqrt price, fees and migration parameters exposed for judgment.
  • Price layer is Pyth-native: 46 on-chain push feeds decoded from raw account bytes (zero RPC key) + Hermes equity feed IDs + PreStocks REST fallback.
